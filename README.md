# DSTCalculator

A CLI calculator for Don't Starve Together that computes damage per hit, hits to kill, and weapon requirements for boss fights.

# Patchnotes [📄](Don-t-Starve-Together-Calculator/UPDATES.md)

A detailed description of the updates with all the new features can be found in the UPDATES.md file.


## Build & Run

```bash
mkdir build && cd build
cmake ..
cmake --build .
./main_app
```

## Features

- **13 bosses**: Bearger, Dragonfly, Moose, Deerclops, Minotaur, Eye of Terror, Bee Queen, Toadstool, Alter Guardian, Wagstaff Robot, Klaus, Antlion, Twins of Terror
- **5 characters**: Wigfrid (x1.25), Wolfgang (x2.0), Wes (x0.75), Wendy (x0.75), Other (x1.0)
- **12 weapons**: Ham Bat, Dark Sword, Glass Cutter, Tentacle Spike, Shield of Terror, and more
- **Debuffs**: Weakness, Moon/Shadow Enemy Weakness, Burn
